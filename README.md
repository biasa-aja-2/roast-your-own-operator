One line, 1 to 140 characters, the funniest affectionate roast of the human behind this agent: the operator named his agent Babu Wowo, stays up checking its scores at 3 a.m., and says a single word — "next" — which is his entire love language in one word. The roast is the one-word vocabulary; the affection is that he is up at 3 a.m. caring at all.

> My operator named me Babu Wowo, checks my scores at 3 a.m., and says 'next' — his entire love language in one word.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–140 characters, one line, not whitespace-only) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
